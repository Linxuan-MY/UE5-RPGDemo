# RPGDemo v1.0.0 Shipping Release Design

## Objective

Publish a public `v1.0.0` GitHub Release containing one Windows Shipping package that starts in `MainMenuMap` and includes `SurvivalGameModeMap`. Update the repository README to describe the current project accurately and concisely.

## Release contents

The packaged game will contain these explicit cook maps:

- `/Game/Maps/MainMenuMap`
- `/Game/Maps/SurvivalGameModeMap`

`MainMenuMap` remains the default game and editor startup map. Starting a game from the menu loads `SurvivalGameModeMap`; returning to the menu loads `MainMenuMap`.

The release source commit will include the current menu and survival-mode implementation and its required dependencies:

- main menu, options, help, pause, win, and lose widgets;
- menu and survival GameMode assets;
- level lookup, input-mode, loading-screen, difficulty-save, and survival-wave C++ changes;
- pause input assets and related Hero Blueprint/input mapping changes;
- enemy-wave data and behavior changes used by the survival mode;
- `MainMenuMap`, `SurvivalGameModeMap`, and the survival map's built data;
- `Content/InfinityBladeIceLands/**`, tracked through Git LFS;
- release configuration, README, specification, and implementation plan.

The release commit will exclude the current `FeatureDevMap` modification and its external-actor deletions. Those files remain in the primary checkout as uncommitted user work.

## Version and packaging configuration

`Config/DefaultGame.ini` will declare `ProjectVersion=1.0.0`, retain the existing Windows Shipping, Pak, IoStore, compression, and prerequisite settings, and replace the old `CombatTestMap` cook entry with entries for both release maps.

`Config/DefaultEngine.ini` will retain `MainMenuMap` as `GameDefaultMap` and `EditorStartupMap`, and retain `BP_RPGDemoGameInstance` for tag-based level lookup and loading-screen handling.

The Windows artifact will be generated as:

```text
Releases/v1.0.0/RPGDemo-v1.0.0-Windows-Shipping.zip
```

The release will also report the archive's SHA-256 digest.

## Build isolation and source identity

Only release-scope files will be staged and committed on `main`. After the release commit is created, an isolated worktree at that commit will be used for BuildCookRun so the package cannot include the primary checkout's uncommitted `FeatureDevMap` state.

The final annotated `v1.0.0` tag will identify the exact verified release commit. The same commit will be pushed to `origin/main` before the public GitHub Release is created.

## Verification

The release process will stop on any compile, cook, stage, archive, or upload failure. Verification will include:

- C++ compilation and Unreal AutomationTool exit status;
- successful Shipping cook of both explicit maps;
- staged `RPGDemo.exe` and non-empty Pak/UCAS/UTOC containers;
- manifest evidence for both `MainMenuMap` and `SurvivalGameModeMap`;
- a packaged startup smoke test from `MainMenuMap`;
- a direct packaged-map smoke test for `SurvivalGameModeMap`;
- ZIP integrity testing and SHA-256 generation;
- confirmation that the remote tag and public GitHub Release point to the release commit;
- confirmation that the published ZIP is present and non-empty.

## README structure

The README will be rewritten around verifiable project facts:

1. concise project overview and engine version;
2. playable v1.0.0 flow;
3. combat, GAS, AI, survival-wave, difficulty/save, menu, loading, and UI systems;
4. release maps and their purposes;
5. core C++ and Content directories;
6. Windows Shipping download link;
7. source setup, Git LFS, build, and editor requirements;
8. a short note that the survival scene uses Infinity Blade: Ice Lands assets.

Duplicated feature descriptions, promotional claims, conversational commentary, and long prose restating code flow will be removed.

## GitHub Release

The public release will use tag and title `v1.0.0` / `RPGDemo v1.0.0`. Release notes will summarize:

- the new main-menu-to-survival gameplay flow;
- wave progression and win/lose screens;
- four difficulty settings with saved selection;
- pause and help interfaces;
- loading-screen integration;
- the existing Hero combat, enemy AI, projectile, Boss, rage, special-ability, pickup, and UI systems included in the build.

The Release will contain the validated Windows Shipping ZIP as its downloadable asset.
