# RPGDemo v0.1.1 Shipping Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `/Game/Maps/CombatTestMap` as a Windows Shipping package, tag the exact source state as `v0.1.1`, and publish the packaged game as a GitHub Release asset.

**Architecture:** Make the packaged game's runtime entry map explicit in project configuration and set the project version to `0.1.1`. Use Unreal Automation Tool to build, cook only `CombatTestMap` and its dependencies, stage, package with IoStore/Pak, archive the staged Windows build, then commit and tag only the release-related source/assets while leaving unrelated `FeatureDevMap` external-actor edits untouched.

**Tech Stack:** Unreal Engine 5.4, Unreal Automation Tool, Windows Shipping target, Git LFS, Git, GitHub CLI, 7-Zip.

---

### Task 1: Configure the v0.1.1 runtime entry point

**Files:**
- Modify: `Config/DefaultEngine.ini`
- Modify: `Config/DefaultGame.ini`
- Modify: `README.md`

- [ ] **Step 1: Set the packaged game default map**

Change `GameDefaultMap` in `Config/DefaultEngine.ini` to:

```ini
GameDefaultMap=/Game/Maps/CombatTestMap.CombatTestMap
```

- [ ] **Step 2: Set the project version and cook map**

Add `ProjectVersion=0.1.1` under `[/Script/EngineSettings.GeneralProjectSettings]`, and replace the existing `MapsToCook` entry with:

```ini
+MapsToCook=(FilePath="/Game/Maps/CombatTestMap")
```

- [ ] **Step 3: Keep the README default-map statement accurate**

Replace the README default-map statement with:

```text
默认地图为 `/Game/Maps/CombatTestMap`，默认 GameMode 为 `/Game/GameModes/BP_BaseGameMode`。
```

- [ ] **Step 4: Verify configuration**

Run:

```powershell
rg -n "GameDefaultMap|ProjectVersion|BuildConfiguration|MapsToCook|默认地图为" Config README.md
```

Expected: `CombatTestMap`, `ProjectVersion=0.1.1`, and `PPBC_Shipping` appear; no active `FeatureDevMap` packaging entry remains.

### Task 2: Build and validate the Windows Shipping package

**Files:**
- Generate (ignored): `Releases/v0.1.1/Windows/**`
- Generate (ignored): `Releases/v0.1.1/RPGDemo-v0.1.1-Windows-Shipping.zip`

- [ ] **Step 1: Build, cook, stage, and archive the map**

Run:

```powershell
& 'E:\UE engine\UE_5.4\Engine\Build\BatchFiles\RunUAT.bat' BuildCookRun `
  -project='E:\UE_Projects\RPGDemo\RPGDemo.uproject' `
  -noP4 -utf8output -platform=Win64 -clientconfig=Shipping `
  -build -cook -map=/Game/Maps/CombatTestMap `
  -stage -pak -iostore -compressed -prereqs `
  -archive -archivedirectory='E:\UE_Projects\RPGDemo\Releases\v0.1.1\Windows'
```

Expected: `AutomationTool exiting with ExitCode=0 (Success)`.

- [ ] **Step 2: Verify the staged package**

Run:

```powershell
Get-ChildItem 'Releases\v0.1.1\Windows' -Recurse -File |
  Measure-Object -Property Length -Sum
Get-ChildItem 'Releases\v0.1.1\Windows' -Recurse -Filter 'RPGDemo.exe'
Get-ChildItem 'Releases\v0.1.1\Windows' -Recurse -Include '*.pak','*.utoc','*.ucas'
```

Expected: a non-empty build, `RPGDemo.exe`, and packaged content containers are present.

- [ ] **Step 3: Create the release archive**

Run:

```powershell
& 'E:\7-Zip\7z.exe' a -tzip -mx=7 `
  'Releases\v0.1.1\RPGDemo-v0.1.1-Windows-Shipping.zip' `
  '.\Releases\v0.1.1\Windows\*'
```

Expected: 7-Zip reports `Everything is Ok`.

- [ ] **Step 4: Test the archive**

Run:

```powershell
& 'E:\7-Zip\7z.exe' t 'Releases\v0.1.1\RPGDemo-v0.1.1-Windows-Shipping.zip'
Get-FileHash 'Releases\v0.1.1\RPGDemo-v0.1.1-Windows-Shipping.zip' -Algorithm SHA256
```

Expected: archive test reports `Everything is Ok` and a SHA-256 hash is printed.

- [ ] **Step 4: Publish the GitHub Release**

Run:

```powershell

  'Releases\v0.1.1\RPGDemo-v0.1.1-Windows-Shipping.zip' `
  --repo Linxuan-MY/UE5-RPGDemo `
  --title 'RPGDemo v0.1.1' `
  --generate-notes `
  --verify-tag
```

Expected: GitHub prints the new Release URL.

- [ ] **Step 5: Verify the remote release**

Run:

```powershell

gh release view v0.1.1 --repo Linxuan-MY/UE5-RPGDemo --json url,isDraft,isPrerelease,tagName,assets
```

Expected: the tag exists, the Release is neither draft nor prerelease, and the ZIP asset is listed.
